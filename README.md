# Agents for Humans Hackathon Project

## Overview
This project aims to build AI agents using the Strands Agents SDK for the Agents for Humans Hackathon.

## Resources
- **Setup & Required Tools**: AWS Account, Strands Agents SDK (Python/TypeScript)
- **Learning Resources**: Getting Started guide, Technical Deep Dive, AWS Open Source Blog, Video Playlist
- **Inspiration Tracks**: Everyday Agents, Professional Agents, Good Neighbor Agents

## Getting Started
1. Create AWS Account: https://signin.aws.amazon.com/signup?request_type=register
2. Install Strands Agents SDK: https://strandsagents.com/docs/user-guide/quickstart/overview/
3. Request AWS Credits: https://forms.gle/Ssr8zLw4afKg114M7 (by Sept 11, 2026)

## Tracks
Choose one track for your agent:
- **Everyday Agents**: Handle repetitive daily tasks (bills, schedules, returns, family coordination)
- **Professional Agents**: Support skilled work (compliance, teaching, research, customer service)
- **Good Neighbor Agents**: Strengthen community connections (volunteer matching, nonprofit support, community organizing)
